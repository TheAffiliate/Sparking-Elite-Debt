🥋 Chuck Norris API Guide

Your complete guide to connecting and retrieving Chuck Norris jokes

🚀 API Overview

Base URL: https://api.chucknorris.io/

Type: Free JSON REST API

Authentication: None required!

Rate Limiting: No limits

💡 Note: This API provides hand-curated Chuck Norris facts and jokes in JSON format. No API key required - just make HTTP requests!

📋 How to Connect - Step by Step

1

Choose Your Endpoint

Select from random jokes, category-specific jokes, search functionality, or get available categories.

2

Make HTTP GET Request

Use any HTTP client (curl, fetch, axios, etc.) to send a GET request to the chosen endpoint.

3

Set Accept Header

Include 'accept: application/json' header to ensure you receive JSON response format.

4

Parse JSON Response

Handle the JSON response containing joke data, including value, id, categories, and metadata.

🎯 Available Endpoints

1. Get Random Joke

GET https://api.chucknorris.io/jokes/random

Returns a completely random Chuck Norris joke.

2. Get Random Joke by Category

GET https://api.chucknorris.io/jokes/random?category={category}

Returns a random joke from a specific category (e.g., dev, explicit, food).

3. Get Personalized Joke

GET https://api.chucknorris.io/jokes/random?name={name}

Returns a personalized joke replacing "Chuck Norris" with the provided name.

4. Search Jokes

GET https://api.chucknorris.io/jokes/search?query={query}

Search for jokes containing specific keywords.

5. Get Categories

GET https://api.chucknorris.io/jokes/categories

Returns an array of all available joke categories.

💻 Code Examples

JavaScript (Fetch API)

fetch('https://api.chucknorris.io/jokes/random') .then(response => response.json()) .then(data => console.log(data.value)) .catch(error => console.error('Error:', error));

Python (Requests)

import requests response = requests.get('https://api.chucknorris.io/jokes/random') if response.status_code == 200: joke = response.json() print(joke['value']) else: print(f"Error: {response.status_code}")

cURL Command

curl --request GET \ --url 'https://api.chucknorris.io/jokes/random' \ --header 'accept: application/json'
